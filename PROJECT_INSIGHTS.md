# Sample Business Insights

Using the included synthetic dataset, the project can answer questions such as:

- Germany has the largest number of sample visa applications.
- Consultant workload can be compared using `COUNT(*)` with `GROUP BY`.
- Average consultation fee can be compared across consultant groups.
- Application statuses can be summarized for management reporting.
- `CASE WHEN` can classify clients into fee bands.
- Subqueries can identify clients paying above the overall average fee.
- `EXISTS` / `NOT EXISTS` can check whether related records are present.
- CTEs make multi-step reporting queries easier to read.
- Window functions can show group averages while keeping each client row visible.

> Note: All data in this repository is synthetic and intended only for learning and portfolio demonstration.
